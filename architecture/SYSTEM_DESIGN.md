# Архитектура Nano Spiking Engine: Детальное проектирование

В этом документе представлена глубокая проработка архитектуры Nano — высокопроизводительного, модульного движка для симуляции спайковых нейронных сетей (SNN).

## 1. Концептуальная схема компонентов (ASCII)

```text
================================================================================
|                                Nano Node                                     |
|  (Rust Orchestrator: Day/Night Loop, Cross-Node Axon Sync, IPC Interface)    |
================================================================================
           |                     ^                       |
           |                     | (Runtime Commands)    |
           v                     |                       v
+-------------------------+      |      +--------------------------------------+
|       Nano Baker        |      |      |           Compute Backend            |
| (Compiler: TOML -> .st) |<-----+      | (Traits: CpuBackend, CudaBackend)    |
+-------------------------+             +--------------------------------------+
           |                                             ^
           |  (Binary State)                             | (SoA Memory Access)
           v                                             |
+------------------------------------------------------------------------------+
|                                  Nano Core                                   |
|   (SoA Memory: NeuronsSoA, SynapsesSoA | LIF Logic | Plasticity Traits)      |
+------------------------------------------------------------------------------+
           |                    |                    |
    [ feature="text" ]   [ feature="vision" ] [ feature="titan" ]
           |                    |                    |
           v                    v                    v
+-------------------+  +-------------------+  +-------------------+
|  Text Processor   |  |   Vision Module   |  |   Titan Memory    |
| (Hash/Byte Spike) |  | (Rate Encoding)   |  | (Momentum-based)  |
+-------------------+  +-------------------+  +-------------------+
```

## 2. Модульность и эффективность (Zero-Cost Modularity)

Nano использует систему `features` в Rust для достижения "нулевой стоимости" (zero-cost) неиспользуемых компонентов.

- **Компиляционная изоляция:** Если модуль `vision` отключен в `Cargo.toml`, его код и зависимости полностью исключаются из бинарного файла.
- **Минимизация ресурсов:** Модели, скомпилированные без определенных модулей, имеют меньший размер на диске и не выделяют память под структуры данных этих модулей во время выполнения (Runtime).
- **Прямой доступ к данным (SoA):** Вся информация хранится в Structure of Arrays, что позволяет вычислительным ядрам (Kernels) обрабатывать данные линейно, минимизируя промахи кэша (Cache Misses).

## 3. Живое управление и командный интерфейс (Runtime Control)

Одной из уникальных особенностей Nano является возможность настройки модели прямо во время ее работы без перезапуска.

### Интерфейс управления (ASCII):
```text
  Пользователь (Команда) ----> [ Nano CLI / Script ]
                                     |
                                     v
  [ Runtime IPC ] <------------ [ Orchestrator (Node) ]
         |                           |
         +--> [ Toggle Modules ] <---+
         |                           |
         +--> [ Adjust Plasticity ] <+
         |                           |
         +--> [ Toggle Thinking ] <--+
```

### Примеры команд:
- `think on / off`: Включение или отключение модуля глубоких рассуждений (Titan Memory).
- `learn enable / disable`: Активация или деактивация фазы Night (структурного обучения).
- `set plasticity_rate 0.05`: Динамическое изменение скорости обучения синапсов.

## 5. Структура развертывания (Standalone AI)

Когда пользователь создает нейросеть (Export), Nano формирует изолированную папку:
```text
/my_nano_model/
├── model.state        # Бинарные веса и топология (SoA)
├── config.toml        # Настройки выбранных модулей
├── run.sh             # Скрипт запуска оркестратора
└── nano_cli           # Облегченная версия CLI для управления
```

## 6. Кросс-языковая интеграция

Nano объединяет сильные стороны нескольких языков для обеспечения гибкости и производительности:

- **Rust (Ядро и Оркестрация):** Гарантирует безопасность памяти и предоставляет высокоуровневые абстракции для управления жизненным циклом нейросети.
- **Python (Исследования и API):** Позволяет быстро создавать прототипы, управлять обучением и визуализировать результаты через привычные инструменты.
- **CUDA/HIP (Вычисления):** Реализует математику симуляции на GPU, обеспечивая параллельную обработку миллионов синаптических связей.
- **C++ (Оптимизации):** Используется для написания критических по скорости низкоуровневых компонентов и расширений.
