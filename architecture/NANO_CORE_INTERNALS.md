# Внутренняя Логика Ядра Nano Core (v4.0)

Этот документ описывает низкоуровневую реализацию вычислительного ядра Nano v4.0 "Ultimate Spiking OS", фокусируясь на структурах данных и GPU-оптимизированных алгоритмах.

## 1. Иерархическая Структура SoA (Structure of Arrays)

Для обеспечения максимальной локальности данных и SIMD-оптимизации, Nano Core разделяет нейроны на **вычислительные блоки (Core Blocks)**.

### Схема блока (ASCII):
```text
[ BLOCK 0 (1024 нейрона) ]
|-- Потенциалы:  [ i32, i32, ... x1024 ] (Aligned 64B)
|-- Пороги:      [ i32, i32, ... x1024 ]
|-- Затухание:   [ i16, i16, ... x1024 ]
|-- Маска спайков: [ u64 x16 ] (Битовое представление активности)
```

### Преимущество:
Вычислительное ядро (Kernel) загружает один блок в кэш L1 и обрабатывает его целиком за один проход, сводя к минимуму обращения к медленной основной памяти (DRAM).

## 2. Асинхронное Ядро (Asynchronous Simulation Kernel)

В версии 4.0 Nano полностью переходит на событийно-ориентированную (Event-driven) симуляцию.

- **Sub-tick Precision:** Разные части сети могут иметь разную частоту обновления. Сенсорные слои могут работать на 2000 Гц, в то время как ассоциативные — на 200 Гц.
- **Event-driven Updates:** Нейрон обновляется только если он получил входной спайк или если его потенциал еще не затух до нуля. Это экономит до 70% вычислительных ресурсов в разреженных сетях.

## 3. Распределение Языков Программирования

| Компонент | Язык | Обоснование |
| :--- | :--- | :--- |
| **SoA Allocator** | **Rust** | Гарантирует отсутствие утечек памяти и правильное выравнивание (alignment). |
| **Spike Propagator** | **CUDA (PTX)** | Использование инструкций `shfl` (shuffle) для обмена данными между потоками GPU без использования глобальной памяти. |
| **Synapse Manager** | **C++** | Эффективная работа с разреженными матрицами (Sparse Matrices) через специализированные библиотеки. |
| **Logic Orchestrator** | **Rust** | Управление переключением между синхронным и асинхронным режимами. |

## 4. Алгоритм Spike Compression (Битовое Сжатие)

Для передачи данных между GPU или узлами используется трехуровневое сжатие:
1.  **Dense Mode:** Передача полной битовой маски (1 бит на нейрон), если активность > 5%.
2.  **Sparse Mode:** Передача списка индексов активных нейронов, если активность < 5%.
3.  **Super-Sparse:** Передача только "дельты" (изменений относительно предыдущего тика).

## 5. Интеграция Spike-Attention (Latent Synapses)

Ядро Nano v4.0 поддерживает слои **Latent Spike-Driven Attention** (на базе низкоранговых матриц):
- Вместо `Softmax(QK^V)` мы используем **Accumulative Attention**.
- Ключи (Keys) и Значения (Values) обновляются только при наличии спайка.
- Это позволяет использовать мощь трансформеров с эффективностью SNN.
