# Глубокая Архитектура Nano v2.1: Синтез Биологии и Вычислений

Этот документ раскрывает вычислительную философию и инженерные решения, лежащие в основе Nano. Мы не просто имитируем нейроны — мы создаем масштабируемую среду для цифровой жизни.

## 1. Вычислительная Философия

Архитектура Nano базируется на трех фундаментальных концепциях:

### 1.1. Integer Physics (Целочисленный Детерминизм)
В отличие от классического ИИ, где "плавающая точка" (`f32/f64`) вносит неопределенность, Nano использует строго фиксированную запятую (`i32`, SCALE=1000). Это гарантирует, что "мысль" нейросети будет идентичной как на суперкомпьютере, так и на микроконтроллере за 5 долларов.

### 1.2. Событийная Природа (Event-driven Efficiency)
Энергия тратится только тогда, когда нейрон "стреляет" (спайк). Это фундаментально отличается от тензорных вычислений, где матрицы перемножаются даже если в них одни нули.

### 1.3. Day/Night Цикл: Биологическая необходимость
Разделение на фазы Day (Инференс) и Night (Эволюция) — это не просто способ синхронизации. Это отражение того, как мозг консолидирует память:
- **Day Phase:** Максимальная скорость реакции, обработка импульсов, Test-Time Training (Titan Memory).
- **Night Phase:** Глубокая структурная перестройка, удаление бесполезных связей (прунинг), рост новых аксонов на основе накопленного за день "сюрприза".

## 2. Иерархия Системы и Масштабирование

Nano спроектирован для работы в распределенной среде.

```text
УРОВЕНЬ 1: Глобальный Кластер (Nano Cluster)
|   [ RDMA / gRPC Spike Bus ]
|   Синхронизирует шарды через "Призрачные аксоны" (Ghost Axons).
|
|-- УРОВЕНЬ 2: Вычислительный Узел (Nano Node - Rust)
|   |   Управляет Day/Night петлей и IPC командами.
|   |
|   +-- УРОВЕНЬ 3: Бэкенд вычислений (Compute Backend)

|       |   Прямой доступ к SoA (Structure of Arrays) для векторизации.
|       |
|       +-- УРОВЕНЬ 4: Функциональные Модули (Zero-Cost Features)
|           |   [ Text, Vision, Titan, New custom... ]
```

## 3. Интеграция Инноваций (Research to Core)

Мы интегрируем лучшие мировые исследования напрямую в ядро Nano:

- **MLA (из DeepSeek):** Используется для сжатия синаптических данных при передаче между узлами кластера.
- **TTT (из Titans):** Реализовано в модуле Titan Memory через импульсное обновление весов на ходу.
- **Selective State (из Mamba):** Принципы селективности внедрены в логику прунинга в фазе Night.

## 4. Глубокое Управление (Runtime Mastery)

Пользователь Nano — это не просто наблюдатель, а дирижер:
- **`mod think boost`**: Динамическое выделение большего количества нейронов под активную задачу.
- **`set plasticity dynamic`**: Автоматическая регулировка скорости обучения в зависимости от сложности входного сигнала.

## 5. Технологический Стек: Синергия Языков

| Слой | Язык | Почему этот выбор? |
| :--- | :--- | :--- |
| **Костяк (Core)** | **Rust** | Безопасность памяти без GC. Это критично для систем, работающих месяцами без перезагрузки. |
| **Мышцы (Day)** | **CUDA** | Экстремальный параллелизм. Тысячи ядер GPU обрабатывают миллионы спайков за миллисекунды. |
| **Нервы (Night)** | **C++** | Гибкая графовая логика и SIMD-инструкции для сложной структурной адаптации. |
| **Разум (User)** | **Python** | Доступ к мировой экосистеме ИИ и удобный интерфейс для обучения. |
