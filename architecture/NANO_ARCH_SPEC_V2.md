# Техническая Спецификация Архитектуры Nano v2

Этот документ является исчерпывающим руководством по архитектуре Nano — высокопроизводительного, модульного движка для симуляции спайковых нейронных сетей (SNN). Проект Nano объединяет принципы биологической правдоподобности с экстремальной инженерной эффективностью.

## 1. Концептуальная схема и Иерархия (ASCII)

Nano спроектирован для бесшовного масштабирования: от одиночных Edge-устройств до глобальных кластеров.

```text
УРОВЕНЬ 1: Nano Cluster (Глобальный оркестратор)
|   (gRPC/RDMA Spike Bus, Балансировка нагрузки, Синхронизация шардов)
|
|-- УРОВЕНЬ 2: Nano Node (Локальный узел - Rust)
|   |   (Day/Night Цикл, Управление IPC, Владение SoA-памятью)
|   |
|   +-- УРОВЕНЬ 3: Compute Backend (Вычислительные ядра)
|       |   (CUDA/HIP Kernels для GPU, SIMD/AVX-512 для CPU)
|       |
|       +-- УРОВЕНЬ 4: Feature Modules (Zero-Cost Модули)
|           |   (Text, Vision, Audio, Titan Memory)
```

## 2. "Zero-Cost" Модульность и Ресурсная Эффективность

Философия Nano строится на принципе "плати только за то, что используешь":
- **Compile-time Resolution:** Неиспользуемые модули исключаются на этапе компиляции через Rust `features`. Это гарантирует отсутствие мертвого кода в бинарном файле и экономию дискового пространства.
- **Runtime Gatekeeping:** Пользователь может мгновенно активировать или деактивировать логику включенных модулей через команды `mod <name> toggle` без перезагрузки системы.
- **Изоляция ресурсов:** Отключенные модули не резервируют VRAM и не потребляют такты GPU.

## 3. Гибридный технологический стек (Language Synergy)

Мы используем оптимальный язык для каждой задачи, обеспечивая максимальную синергию:

| Слой системы | Языки | Роль и Технологии |
| :--- | :--- | :--- |
| **Оркестрация** | **Rust** | `nano-node`. Безопасная многопоточность (`tokio`), владение SoA-буферами, IPC. |
| **Вычисления (Day)** | **CUDA / HIP** | "Мышцы". Проход по графу спайков, вычисление токов. Прямая работа с регистрами GPU. |
| **Эволюция (Night)** | **C++ / Rust** | "Логика". Прунинг, рост аксонов. Интеграция с графовыми библиотеками и SIMD. |
| **Интерфейс (API)** | **Python** | "Лицо". `nano-python` (`PyO3`). Исследования, R&D, удобная настройка и визуализация. |

## 4. Жизненный цикл данных и Управление (ASCII)

Nano позволяет управлять нейросетью "на лету" (Live Tuning), предоставляя пользователю полный контроль над динамикой модели.

### Схема управления и данных:
```text
  [ USER (Python/CLI) ] --- (Команды: think, tune, save) ---> [ Nano Node (Rust) ]
                                                                    |
  1. ВХОД (Input)        2. ДЕНЬ (Day - CUDA)        3. ОШИБКА (Surprise)   |
  [ Текст/Пиксели ] ---> [ Спайки в SoA ] ------> [ Ошибка предсказания ] --+
        ^                       |                         |
        |                       v                         v
  [ Spike Encoding ]     [ Синаптическая ]       [ Обучение Titan Mem ]
                         [ передача      ]       [ (Test-Time Train)  ]
                                                        |
                                                        v
                                                 4. НОЧЬ (Night - C++)
                                                 [ Пластичность GSOP  ]
                                                 [ Структурный прунинг]
```

## 5. Решение критических узких мест (Weak Points Mitigation)

1.  **Масштабируемость памяти (VRAM Limit):**
    - *Решение:* **Distributed Sharding**. Разделение графа нейронов между несколькими GPU/Узлами с использованием асинхронных прокси-связей (Ghost Axons v2).
2.  **Латентность синаптической передачи:**
    - *Решение:* **Spike Compression**. Передача битовых масок активности вместо списков индексов, что снижает нагрузку на шину PCIe/Network в 4-8 раз.
3.  **Thread Contention в фазе Night:**
    - *Решение:* **Lock-free Topology Updates**. Использование Double Buffering для SoA. Пока один буфер обрабатывает тики, второй модифицируется фоновым потоком.
4.  **Точность вычислений i32:**
    - *Решение:* **Adaptive Scaling**. Автоматическая регулировка масштаба (SCALE) для предотвращения переполнения при сохранении детерминизма "целочисленной физики".

## 6. Автономное развертывание и AI v2

Nano поддерживает экспорт обученных моделей в изолированные папки (`Standalone AI`), которые содержат:
- Бинарный снимок состояния (`.state`).
- Оптимизированный бинарный файл `nano_cli`.
- Скрипты для запуска и дообучения (`Continuous Learning`).
Это позволяет пользователю легко создавать новые версии нейросетей, клонировать их и эволюционировать в разных направлениях.
