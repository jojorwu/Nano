# Пример: Классификация текстовых команд

Этот пример демонстрирует, как использовать Axicor для обучения нейросети простым текстовым командам.

## Что происходит:
1. **Baking:** Создается модель на 500 нейронов с включенным модулем Titan Memory.
2. **Training (Exposure):** Скрипт подает на вход нейросети набор команд («ВКЛЮЧИТЬ СВЕТ», «ИДИ ВПЕРЕД» и т.д.) несколько раз.
3. **Learning:** Благодаря пластичности GSOP и памяти Titan, нейросеть адаптируется к этим паттернам.
4. **Verification:** В конце скрипт сравнивает активность нейронов для знакомых команд и для совершенно новой («НЕИЗВЕСТНАЯ КОМАНДА»).

## Как запустить:
1. Убедитесь, что у вас установлен Rust.
2. Запустите скрипт обучения:
   ```bash
   python3 examples/commands/train.py
   ```

## На что обратить внимание:
- **Spikes generated:** Количество импульсов, генерируемых на каждое слово. Со временем оно стабилизируется.
- **Structural Evolution:** В конце каждой итерации вы увидите, как меняется количество синапсов (нейросеть удаляет лишние связи и создает новые).
- **Persistence:** Обученная модель сохраняется в `examples/commands/classifier.state` и содержит в себе накопленный опыт и словарь.
