# Пример: Модуль Зрения (Vision)

Этот пример демонстрирует, как Nano обрабатывает изображения, превращая пиксели в импульсы.

## Как это работает:
1. **Rate Encoding:** Модуль зрения берет интенсивность каждого пикселя (0-255) и превращает её в начальный потенциал для соответствующего нейрона.
2. **Spiking:** Чем ярче пиксель, тем больше вероятность, что нейрон, отвечающий за эту область, "выстрелит" импульсом в этом тике.
3. **Architecture:** В этом примере используется 1000 нейронов, из которых первые 784 (28x28) зарезервированы под входные данные от изображения (например, из датасета MNIST).

## Как запустить:
1. Запеките модель:
   ```bash
   cargo run -p axicor-cli -- bake --blueprint examples/vision/blueprint.toml --output vision.state
   ```
2. Подайте на вход любое изображение (протестировано на PNG/JPG):
   ```bash
   cargo run -p axicor-cli -- run --model vision.state --image path/to/your/image.png
   ```

## Особенности:
- **Resizing:** Модуль автоматически считывает изображение любого размера, но модель в этом примере ожидает, что входные нейроны будут соответствовать разрешению 28x28.
- **Structural Plasticity:** Как и в других модулях, ночная фаза (Night Phase) будет перестраивать связи в зависимости от того, какие визуальные паттерны чаще всего встречаются.
