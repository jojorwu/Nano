# Масштабирование контекстных окон: Технологии и методы (2024-2025)

Для работы с контекстом более 2 миллионов токенов в 2024–2025 годах были внедрены ключевые архитектурные новшества, направленные на преодоление ограничений KV-кэша.

## Основные методы оптимизации

### 1. Multi-Head Latent Attention (MLA)
Это решение, популяризированное DeepSeek (V2/V3), которое радикально сокращает размер KV-кэша за счет:
- **Низкорангового сжатия:** Ключи и значения сжимаются в скрытые (латентные) векторы.
- **Декомпрессии "на лету":** При инференсе веса декомпрессируются только для активных вычислений.
Это позволяет загружать в 5–10 раз больше контекста в ту же память GPU по сравнению с традиционным Multi-Head Attention.

### 2. Долговременная нейронная память (Titans)
В отличие от статического окна контекста, архитектура Titans (Google Research, 2025) предлагает:
- **Нейронную память (Neural Memory):** Слой, который обучается (Test-Time Training) прямо в процессе инференса.
- **Сжатие истории:** Все, что выходит за пределы текущего окна внимания, "записывается" в веса этого слоя, а не просто удаляется.

### 3. Ring Attention и распределенный контекст
Для сверхдлинных последовательностей используется распределение вычислений внимания по кольцу между несколькими GPU. Это позволяет обрабатывать огромные объемы данных (например, целые видео или кодовые репозитории), не ограничиваясь памятью одной видеокарты.

### 4. Линейная рекуррентность (Mamba / RWKV)
Модели на базе пространств состояний (SSM) и линейного внимания предлагают фиксированный размер скрытого состояния. Весь прошлый контекст сжимается в этот вектор, что дает:
- **Линейную сложность:** Время обработки не растет квадратично с длиной текста.
- **Бесконечное окно:** Теоретическая возможность обрабатывать данные любой длины, хотя на практике качество может постепенно падать из-за потерь при сжатии.

## Значение для Nano
Комбинация MLA для краткосрочного контекста (потенциалы спайков) и Titans-подобной нейронной памяти (модуль Titan) является стратегическим направлением развития Nano для достижения "вечной" памяти без потери детализации.
