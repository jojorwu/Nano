# Архитектура Nano v4.0 "Ultimate Spiking OS"

Этот документ описывает внутреннюю структуру и принципы работы модульной спайковой нейронной сети Nano v4.0 с высокопроизводительным GPU бэкендом и распределенным интеллектом.

## 1. Основные принципы

Система построена на трех китах:

1.  **Integer Physics (Целочисленная физика):** Все вычисления (потенциалы, веса, затухание) выполняются с использованием фиксированной запятой (`i32`). Базовый масштаб `SCALE = 1024` (соответствует 1.0). Это обеспечивает детерминизм и максимальную скорость через битовые сдвиги (`>> 10`) на любом железе.
2.  **Structure of Arrays (SoA):** Данные нейронов и синапсов хранятся в плоских параллельных векторах, а не в объектах. Это оптимизирует использование кэша процессора и упрощает будущую интеграцию с GPU (SIMD/CUDA).
3.  **Day/Night Cycle:** Разделение работы на быструю фазу инференса (Day) и медленную фазу обучения/перестройки (Night).

## 2. Структура Workspace (Crates)

Проект разделен на несколько специализированных библиотек и приложений (Nano v4.2 Multi-Language):

-   `genesis-core`: Ядро (Rust). Содержит типы данных (SoA), базовую логику спайков и FFI-интерфейсы для Zero-Copy доступа.
-   `genesis-compute`: Вычислительный бэкенд (Rust + C++ + CUDA). Реализация симуляции на разных языках и железе.
-   `genesis-python` & `genesis-client`: SDK для Python. Позволяет управлять симуляцией и строить модели на Python.
-   `genesis-baker`: Компилятор моделей. Читает TOML-чертежи (blueprints) и "запекает" их в бинарные файлы состояния.
-   `genesis-node`: Оркестратор. Управляет жизненным циклом модели и динамически выбирает бэкенды (CPU, C++, CUDA, WGPU).
-   `nano-cli`: Командный интерфейс для пользователя.

## 3. Модульная система

Функционал нейросети собирается из независимых модулей через систему `features` в Rust и конфигурацию в TOML:

-   **Titan Memory:** Адаптивная память, которая учится прямо во время работы (test-time) через упрощенный градиентный спуск с моментом.
-   **Text Processor:** Токенизатор и кодировщик, превращающий слова в паттерны импульсов.
-   **Vision Module:** Модуль интенсивного кодирования (Rate Encoding) для обработки изображений.

## 4. Формат данных

-   **Blueprints (.toml):** Описание архитектуры (кол-во нейронов, синапсов) и список включенных модулей.
-   **Model State (.state):** Бинарный файл (сериализация `bincode`), содержащий все веса, потенциалы, топологию синапсов и накопленный словарь. Автоматически сохраняется после каждого запуска.

## 6. Nano v4.0: The Ultimate Spiking OS

Версия 4.0 — это кульминация развития архитектуры, объединяющая биологическую точность и экстремальную производительность.

### Ключевые инновации v4.0:
1.  **Metaplasticity (Hyper-Learning):** Система теперь не только меняет веса, но и динамически подстраивает саму скорость обучения (learning rate) для каждого нейрона, адаптируясь к стабильности среды.
2.  **Selective Dendritic Processing (SDP):** Движок автоматически пропускает вычисления для нейронов с закрытыми дендритными шлюзами, что дает кратный прирост скорости в сложных иерархических моделях.
3.  **Device-Resident State:** Полный перенос состояния сети на GPU. Веса и потенциалы живут в видеопамяти, минимизируя дорогостоящие пересылки данных по шине PCIe.
4.  **Semantic Versioning:** Внедрена система контроля версий моделей, гарантирующая целостность знаний при обновлении движка.
5.  **Layer-wise Grouping:** Поддержка логического разделения нейронов на слои с уникальными гиперпараметрами через централизованный `nano.toml`.
6.  **SMBP (Active Backpropagation):** Полноценная аппаратная реализация активной обратной связи для моделирования процессов внимания и памяти.

## 5. Логика работы (Tick Loop)

Один тик симуляции в `genesis-node` выглядит так:

1.  **Day Phase (Inference):**
    -   Сбор внешних входов (Text, Vision, Audio, RL Observations).
    -   Распространение импульсов через синапсы (CPU/GPU Kernels).
    -   Чтение сигналов из Titan Memory.
    -   Обновление потенциалов нейронов и генерация новых спайков.
2.  **Night Phase (Evolution):**
    -   Срабатывает каждые N тиков.
    -   Обновление весов по закону пластичности (GSOP).
    -   Обучение Titan Memory на основе "сюрприза" (ошибки предсказания).
    -   Структурная эволюция: удаление слабых связей (pruning) и создание новых между активными нейронами (growth).
