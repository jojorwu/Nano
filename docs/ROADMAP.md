# Roadmap развития Axicor Spiking Engine

В этом документе описаны планы по развитию нейросети и добавлению новых функций.

## 1. Краткосрочные цели (Альфа-стадия)

-   **GPU Acceleration (CUDA/ROCm):** Реализация `CudaBackend` в `genesis-compute` для переноса вычислений SoA на видеокарты NVIDIA.
-   **SIMD Оптимизация:** Использование инструкций процессора (AVX-512, NEON) для ускорения `CpuBackend`.
-   **Расширенная пластичность:** Добавление модуля STDP (Spike-Timing-Dependent Plasticity) как альтернативы GSOP.
-   **Улучшенный токенизатор:** Интеграция Byte-Pair Encoding (BPE) для более качественной работы с текстом.

## 2. Среднесрочные цели (Бета-стадия)

-   **Distributed Computing:** Поддержка работы одной модели на нескольких ПК через сетевой протокол (шардирование графа).
-   **Audio Module:** Модуль для обработки звуковых волн и превращения их в спайки (SNN-аудиопроцессинг).
-   **3D Визуализация:** Создание `genesis-ide` на движке Bevy для наблюдения за активностью нейронов и ростом синапсов в реальном времени.
-   **Reinforcement Learning:** Интеграция с Gymnasium для обучения агентов в виртуальных средах.

## 3. Долгосрочные цели (AGI-ориентированные)

-   **Ghost Axons:** Реализация механизма "призрачных аксонов" для более сложной структурной эволюции между удаленными слоями.
-   **Hierarchical Memory:** Многоуровневая Titan-память (краткосрочная, среднесрочная и вечная).
-   **Self-Reflection:** Механизмы мониторинга собственного состояния сети для автоматической настройки гиперпараметров (learning rate, thresholds).
-   **Multi-modal Fusion:** Глубокая интеграция зрения, текста и звука в едином латентном пространстве спайков.

## 4. Исследовательские направления

-   Адаптация новых архитектур (например, Mamba или Liquid Networks) под спайковую парадигму.
-   Исследование энергетической эффективности SNN для запуска на Edge-устройствах (ESP32, RISC-V).
-   Формальное доказательство стабильности GSOP при бесконечном росте сети.
