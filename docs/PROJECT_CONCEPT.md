# Концепция проекта Axicor: Модульная спайковая нейросеть

Проект Axicor — это инновационный движок для создания биологически правдоподобных нейронных сетей с упором на максимальную модульность и эффективность ресурсов. Проект находится на начальной стадии разработки.

## Основная идея

Главная цель Axicor — предоставить пользователю возможность "собирать" свой собственный ИИ из независимых модулей.

### Принципы модульности:
- **Гибкая конфигурация:** Пользователь сам решает, какие функции (зрение, текст, специфические виды памяти) нужны его модели.
- **Экономия ресурсов:** Если модуль отключен, он не занимает место на диске и не потребляет оперативную или видеопамять во время работы нейросети.
- **Индивидуальный подход:** Система не навязывает лишний функционал — пользователь получает ровно то, что ему необходимо для конкретной задачи.

## Технологический стек

Для достижения максимальной производительности и кроссплатформенности проект использует комбинацию современных языков и технологий:
- **Rust:** Ядро системы, управление памятью и высокоуровневая логика симуляции.
- **Python:** Удобный интерфейс для обучения, проведения экспериментов и интеграции с внешними средами (например, Gymnasium).
- **CUDA / HIP:** Высокопроизводительные ядра для параллельных вычислений на GPU (NVIDIA и AMD).
- **C++:** Низкоуровневые оптимизации и взаимодействие с аппаратным обеспечением.

## Текущий статус

Проект находится на этапе активной разработки фундаментальных компонентов. Основное внимание уделяется:
1. Реализации целочисленной физики (Integer Physics) для детерминизма.
2. Оптимизации структуры данных SoA (Structure of Arrays).
3. Разработке механизма "запекания" (Baking), который формирует финальный бинарный файл модели только из выбранных модулей.

Axicor стремится стать основой для создания воплощенного интеллекта (Embodied AI), способного работать в реальном времени как на мощных серверах, так и на компактных Edge-устройствах.
