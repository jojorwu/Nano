# Жизненный цикл нейросети Nano

Этот документ описывает все этапы существования модели в экосистеме Nano — от выбора модулей до развертывания и управления в реальном времени.

## 1. Проектирование (Module Selection)
Пользователь определяет функциональность модели в TOML-чертеже (blueprint):
- `text = true`
- `vision = false`
- `titan = true`
На этом этапеNano гарантирует, что неиспользуемые модули не будут потреблять ресурсы.

## 2. Запекание (Baking)
Компилятор `Nano Baker` читает чертеж и создает начальный бинарный файл состояния (`.state`):
- Выделение SoA-памяти только под выбранные модули.
- Инициализация начальной топологии синапсов.
- Формирование весов LIF-нейронов.

## 3. Обучение (Training)
Процесс обучения в Nano проходит в Day/Night циклах. Модель может обучаться:
- **Базовое обучение:** Формирование первичных связей на больших наборах данных.
- **Continuous Learning (Непрерывное обучение):** Модель продолжает адаптироваться во время работы.
- **Fine-tuning (Дообучение):** Возможность взять существующую модель и доучить ее на новых специфических данных без потери старых знаний.

## 4. Экспорт и Развертывание (Standalone AI)
Когда модель готова, пользователь может экспортировать ее в отдельную папку:
- `nano --export "MyAgent"`
Создается папка с именем модели, содержащая все необходимые файлы для запуска на целевом устройстве.

## 5. Работа и Живое управление (Runtime Control)
Запущенная модель (`./run.sh`) поддерживает управление через командный интерфейс в реальном времени.

### Основные команды управления:
- **`module think <on|off>`**: Включает или выключает модуль рассуждений (Titan) "на лету".
- **`set plasticity <value>`**: Изменяет скорость обучения во время работы.
- **`save`**: Принудительное сохранение текущего состояния весов.
- **`night now`**: Принудительный запуск фазы перестройки топологии.

## 6. Цикл дообучения (Iterative Improvement)
Развернутую модель можно в любой момент вернуть в режим интенсивного обучения для улучшения характеристик, после чего снова экспортировать обновленную версию.

---

### Сводная схема жизненного цикла:
```text
[ Чертеж ] -> ( Baker ) -> [ .state файл ] -> ( Node: Обучение )
                                                   |
                                                   v
[ Runtime Настройка ] <--- ( Управление ) <--- [ Экспорт в папку ]
```
